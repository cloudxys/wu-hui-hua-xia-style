## 〇、风格锚点（最重要，先读这一节）

本风格瞄准的是《无悔华夏》**武将/帝王立绘**的观感，不是"把照片加个滤镜"。它的构成是：

| 构件 | 硬指标（可肉眼核对） |
|---|---|
| **人物块面（核心）** | 脸、鼻、下巴、衣物、器物全部由**大块锐利切面**构成：每块**内部完全平涂单色**，块与块之间是**硬边直接切换**，**过渡为零**。禁止柔和明暗过渡、晕染、体积渲染、柔光。全脸色阶控制在 **2–3 块**（如：亮面 / 侧面 / 暗面），不是连续渐变 |
| **从简原则（核心）** | 一切装饰一律概括：**珠串每颗用一小块单色圆点表示、大小一致，不加高光/反光/立体感**；纹样简化为**一到两个概括块面或粗线条**（不做逐笔花纹）；衣褶只画**两三道粗折线**；帽饰结构线直、少、硬。宁可少画，不可画细 |
| 轮廓线 | **人物外轮廓、服饰结构线、器物边缘**用明显加粗的深色线；**五官区域与背景内部不加粗线** |
| 面部 | 浅色块 + 大块阴影，**五官极简**（鼻梁一条短线、嘴角一小笔）；脸的明暗是**刀切一样的分块**，不是晕染 |
| 眼睛（强制） | **完全留空、一个都不画**：没有眼珠、眼白、虹膜、瞳孔、睫毛、高光、亮色点；也不画深色眼影或粗黑眼线。眼位只用**眉弓下的一块浅暗面**带过，至多一条极短的淡线。**"有眼睛"本身就是不合格** |
| 皮肤质感 | 只有硬边块面明暗，**没有**毛孔、皱纹、睫毛、皮肤纹理，**也没有**柔和过渡与高光反射 |
| 配色 | 低明度、低饱和的国风色板，详见文末色板表；**禁止高饱和色、霓虹色、纯黑纯白大面积** |
| 背景处理（强制） | 保留原构图、元素位置与空间层次，用**柔和的渐变云气**重绘：天空/云雾/远山用**平涂色块 + 柔边淡入**，同类元素 3–5 层明度**层层模糊过渡、层间带雾气**，保留空气感与纵深感；幽蓝灰或暖褐灰调；**禁止硬边色块、马赛克/像素块感、棋盘格、明显几何切块**，也禁止照片纹理与噪点 |
| 背景明度 | 层次要"看得见但很柔和"（相邻层明度差约 8–15%），**禁止**大面积留白、纯色空白、死灰色雾 |
| **人物硬 / 背景柔（关键分工）** | **人物用硬切面、平涂、零过渡、加粗墨线；背景用柔边渐变、雾气、模糊过渡。** 两者色板统一，但处理方式必须相反——把人物也做成晕染，或把背景做成硬方块，都算不合格 |

## 一、正向提示词（模板）

> 【角色锚定】保持原图的构图、人物姿态、人物数量、位置朝向以及背景场景布局完全不变，将整张图重绘为《无悔华夏》风格的新国风扁平插画。
>
> 【画面构成】人物部分由**大块锐利几何切面**拼接而成：每块**内部完全平涂单色、零过渡**，块与块之间**硬边直接切换**，明暗只有 2–3 块，像一刀一刀切出来的立体块面；**禁止柔和明暗过渡、晕染、体积渲染、柔光与皮肤高光**。用**明显加粗的深色墨线**勾人物外轮廓、衣物结构线与器物边缘，线条肯定、有粗细变化；面部与背景内部不加粗线。
>
> 【从简原则】整体**从简、概括、宁少勿细**：珠串每颗只用一小块单色圆点、大小一致，**不加高光、反光与立体感**；纹样简化为**一到两个概括块面或粗线条**，不做逐笔花纹；衣褶只画**两三道粗折线**；帽饰结构线直而少。不要精细刻画，要的是概括力。
>
> 【人物处理】画面中的所有人物：面部用**浅色块 + 大块阴影**构成，脸、鼻、下巴的明暗是**刀切一样的分块、无晕染**；五官高度概括——鼻梁一条短竖线、嘴角一小笔。
>
> 【眼睛 · 强制不画】画面的所有人物**都不画眼睛**：眼位完全留空，没有眼珠、眼白、虹膜、瞳孔、睫毛、高光与任何亮色点；也不画深色眼眶、眼影或粗黑眼线。眼窝处只用**眉弓下的一块浅淡暗面**带过，至多一条极短的淡线；靠眉形、发型、胡须与脸型轮廓来识别身份。**只要画面上出现了"眼睛"这个形状或亮点，就是不合格，必须重画。**
>
> 【背景处理 · 强制】背景保留原图的构图、元素位置与空间层次，用**柔和的云气渐变**重绘：天空、云雾、远山、建筑、墙面、地面、旗帜、器物、人群用**平涂色块 + 柔边淡入**表现，同类元素约 3–5 层明度**层层模糊过渡、层间带雾气**，保留空气感与纵深感，色调走幽蓝灰或暖褐灰。**禁止硬边色块、马赛克/像素块感、棋盘格与明显几何切块**，也禁止照片纹理与噪点；保留原场景结构与位置可辨，背景对比度与清晰度**低于人物**。
>
> 【硬柔分工】**人物硬、背景柔**：人物用硬切面平涂加粗墨线，背景用柔边渐变与雾气——两者色板统一，但处理方式相反，不许把人物画成晕染，也不许把背景画成方块。
>
> 【质感】扁平、干净、高清，游戏立绘质感；画面整体是"手绘的平涂插画"，不是"加了滤镜的照片"。

## 三、失败现象 → 修正指令（按需追加到正向提示词末尾）

| 现象 | 追加指令 |
|---|---|
| **人物块面感弱 / 晕染过渡太多** | `人物的脸、鼻、下巴、衣物必须改成大块锐利切面：每块内部完全平涂单色、零过渡，块与块之间硬边直接切换，明暗只保留两到三块；禁止柔和明暗过渡、晕染、体积渲染、柔光与皮肤高光。像一刀一刀切出来的立体块面。` |
| **细节过于精致写实（珠串逐颗、纹样繁复）** | `整体从简概括：珠串每颗只用一小块单色圆点、大小一致，不加高光、反光与立体感；纹样简化为一到两个概括块面或粗线条，不做逐笔花纹；衣褶只画两三道粗折线；帽饰结构线直而少。宁可少画，不可画细。` |
| **画风偏厚涂 / 商业国风立绘** | `去掉厚涂与体积感，回到平涂加硬切面加加粗墨线；画面要概括、扁平、干净，不要精细刻画。` |
| 背景没处理 / 像原照片 | `背景必须逐元素重新绘制：天空、云雾、远山、建筑、墙面、地面、旗帜、器物、人群全部用平涂色块加柔边淡入重画，禁止保留任何照片纹理与噪点。` |
| **背景变成硬边色块 / 马赛克 / 像素块** | `背景必须改为柔和的云气渐变：同类元素三到五层明度层层模糊过渡、层间带雾气，边界柔化，禁止硬边色块、马赛克、像素块、棋盘格与几何切块。` |
| 背景糊成一片 / 没有层次 | `背景保留三到五层明度层次，逐层柔和淡入，相邻层明度差约百分之八到十五，保持原场景的结构可辨。` |
| 背景太碎 / 太抢眼 | `减少背景层次与细节，背景对比度与清晰度降低到人物之下，人物保持视觉焦点。` |
| **人物画出了眼睛** | `所有人物一律不画眼睛：眼位完全留空，没有眼珠、眼白、虹膜、瞳孔、睫毛、高光与任何亮色点，也不画深色眼眶、眼影和粗黑眼线；眼窝只用眉弓下一块浅淡暗面带过，只要出现眼睛的形状或亮点就重画。` |
| 人物数量、姿态走形 | `严格锁定原图中每个人物的数量、站位、朝向与动作，一律不得增删或改变姿态。` |
| 面部细节过多 / 太写实 | `面部只用浅色块与大块阴影构成，明暗是刀切一样的分块、无晕染，五官极简，不刻画毛孔、皱纹、睫毛等细节。` |
| 画面发灰发糊 / 像滤镜 | `提高块面对比度，去除照片式虚化与死灰色雾；背景柔和但结构可辨。` |
| 轮廓线太弱 | `人物外轮廓与服饰结构线明显加粗、颜色加深，线条肯定清晰。` |
| 颜色太艳 / 太现代 | `改用低明度低饱和国风色板：赭石、土黄、青灰、墨黑、暗红、米白，禁止高饱和与霓虹色。` |
| 长相变化过大 | `保留每个人物的脸型轮廓、发型、胡须与帽饰特征，保持可识别性。` |

## 五、国风低饱和色板（取自《无悔华夏》立绘）

**暖色系**（赭石、金饰、土黄）：`#A88149` `#BCA88E` `#8C6A4A` `#C4A574` `#E8DCC6`

**冷灰系**（天空、远山、墙面、青灰）：`#C8CCD2` `#9599A6` `#6E7280` `#8A7F72`

**肤色系**（面部浅色块与阴影，**两块之间直接切换、不做渐变**）：`#E3C4A8` `#D3A886` `#BE9270`

**点缀红**（旗帜、披风、饰带，低饱和暗红）：`#A63B32` `#C0392B`

**底色 / 高光米白**：`#F0EAE0` `#E8DCC6`

用法：以上为**目标色域**，不是逐像素填充表。转换后整图主要色相应落在这几组里；若出现高饱和或明显不属于该色板的颜色，视为未达标。

**用途区分**：人物用**硬边块面平涂 + 加粗轮廓**（零过渡、2–3 块色阶）；背景用**同一色板的柔边云气渐变**（例如天空 `#F0EAE0`→`#C8CCD2`，远山 `#C8CCD2`→`#9599A6`→`#6E7280` 层层模糊淡入，层间带雾）。两处色板一致，但处理方式**相反**——人物硬、背景柔。

## 六、生成后 30 秒自检清单（逐条打勾）

**一票否决项（前 5 条）**

1. □ **人物完全没有眼睛**：放大看不到眼珠、眼白、瞳孔、睫毛、眼线、高光；眼位是留空的浅色面
2. □ **人物是硬切面**：脸/鼻/下巴/衣物放大后看不到柔和过渡与晕染，块与块之间是硬边直接切换，明暗只 2–3 块
3. □ **从简到位**：珠串是单色小圆点、无高光无立体感；纹样只是概括块面或粗线条；衣褶只有两三道粗折线
4. □ **背景是柔边云气渐变**，不是硬边色块/马赛克/像素块；层次 3–5 层、层间带雾、有空气感
5. □ 人物数量、姿态、位置与原图一致

**其余检查项**

6. □ 背景每个元素都已重绘，全图找不到未处理的原始像素与照片纹理
7. □ 背景对比度与清晰度明显低于人物（人物硬而实，背景柔而虚）
8. □ 人物外轮廓/服饰结构线明显加粗
9. □ 面部是浅色块 + 大块阴影，不是深色块 + 黑眼线
10. □ 主色落在第五节色板内，人物与背景色板统一
11. □ 人物仍可识别，没有变成另一个人

任一条不满足 → 回原图重生成，并按第三节追加对应指令。
