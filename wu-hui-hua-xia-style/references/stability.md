# 稳定性规范（v1.5.0 新增）

本文件针对反复出现的**不稳定**问题：同样的提示词，跑出来的图时好时坏——有时硬切面到位但画了眼睛，有时背景正确但细节又变精细。原因不是规则写错，而是**规则太长、优先级平均**，模型会挑它擅长的做、跳过它不擅长的。

解决办法三条：**加权重、给正面替代、量化验收**。

---

## 一、优先级（出现冲突时按此顺序取舍）

1. **不画眼睛**（最高，对抗模型先验，最难保证，必须每次单独核）
2. **人物硬切面**（块内平涂、块间硬边零过渡）
3. **背景柔边云气渐变**（不是硬方块，也不是水彩晕染）
4. **从简概括**（珠子是圆点、纹样是粗线、头发不描丝）
5. **构图锁定**（人数、姿态、位置、背景布局）
6. 其余（配色、分辨率等）

**只有前 3 条达标才算这张图能用**；第 4、5 条是扣分项，第 6 条是硬参数。

---

## 二、给"不要眼睛"一个正面替代（关键技法）

只写"不要画眼睛"，模型会用自己的默认方式**补上面部特征**——这是它训练时的先验，抹不掉。必须**指定那块面积该画什么**，把负向约束变成正向填充。

**注意：只封"眼珠"不够**。实测发现，封了眼珠之后模型会改用**上眼睑线 + 睫毛线**把眼型"勾勒"出来，看上去仍然是一双闭着的眼睛。所以必须把**整个眼周区域**一起封死：

> **眼周区域**（从眉弓下沿到颧骨上沿、内眼角到外眼角这一整片）**只由皮肤色块构成**：
> 一整块或两块最简色块（眉弓下暗面 / 颧骨亮面），**块间直接硬边相接**。
> 该区域内：**没有眼睛形状、没有上眼睑线、没有睫毛线、没有双眼皮线、没有眼白、没有瞳孔、没有高光、没有褶皱阴影**——一条线都不画。
>
> 说话方式：**不要描述"闭着的眼睛"**（模型会照着画一条闭眼线）；直接说"**眼部区域是一块皮肤平面**"。

同理，"不要细描头发"也要给替代：

> 头发 = **3–5 块大色块**（亮面 / 中间面 / 暗面 / 高光），块间硬边；**不画发丝**，鬓角与发际线用一条粗线带过。
> 胡须 = **2–3 块概括暗面**贴在唇周与下颌，**不画胡茬**（逐根短线的质感一律禁止）。

### 背景为什么反复跑成水彩（用词陷阱）

"**柔边**""**柔和渐变**"这类词会把模型引向**水彩/水墨**媒介——结果是晕染斑块、脏点、笔触痕迹。应当改说**"干净平涂 + 单向均匀渐变"**：

> 背景用**干净平涂加单向均匀渐变**：每层是一个纯色块，层内颜色沿一个方向均匀变化，**没有纹理、没有笔触、没有斑点、没有颗粒**，看不到水彩或水墨的痕迹。
> **离散色块只给建筑、墙面、屋顶、器物等硬边物体用**；天空、云雾、远山一律用连续渐变。

> 这条踩坑过两次：v1.2 写成"硬边色块"→ 出了马赛克；v1.3/v1.5 写成"柔边渐变"→ 出了水彩。**"干净平涂 + 均匀渐变 + 无纹理"**是目前唯一没跑偏的说法。

## 三、量化验收（把"感觉"变成"数字"）

生成后按这 5 条数，**不用审美判断**：

| 检查项 | 量化标准 | 不通过就 |
|---|---|---|
| 眼睛 | **眼部整片区域**内：色块数 = 1–2，**线条数 = 0**（含上眼睑线、睫毛线、双眼皮线） | 重画，并追加第二节的"眼部区域是一块皮肤平面"句 |
| 面部硬边 | 脸的明暗色阶 **≤ 3 块**，块与块之间**看不到过渡带** | 追加"硬切面"指令 |
| 背景 | 层次 **3–5 层**；**纹理数 = 0**（无水彩斑块、无笔触、无颗粒、无脏点）；硬边离散块**只出现在建筑/器物上** | 追加"干净平涂 + 单向均匀渐变"指令 |
| 装饰从简 | 珠子 = 单色圆点；头发/胡须**不出现逐根线条或胡茬** | 追加"从简"指令 |
| 轮廓 | 人物外轮廓线宽 **明显大于发丝与褶皱纹** | 追加"加粗墨线"指令 |

**重试规则**：不达标 → 用同一张原图重生成，**最多 2 次**。

**第 2 次仍不达标，不再改词，直接换手段**（实测纯文字提示词的天花板就在这里）：

1. **先补风格锚点图**：让用户提供 1–2 张已确认风格的样张（本技能此前的满意成品、或《无悔华夏》官方立绘），与原图一起传入；
2. **用第四节的稳定版提示词**，不要现场改词；
3. 同时**在提示词里点明锚点图的作用**：「以图 1 的构图与人物为准，以图 2 的画风、背景处理与配色为准」；
4. 仍不达标 → 如实告诉用户：当前工具/模型难以稳定复现该风格，说明已尝试的指令与具体偏差，**不要继续消耗、也不要交付一张自己核不过的图**。

> 依据：本项目实测过 3 轮纯文字迭代（v1.4 硬切面 → v1.5 眼睛正面替代 → v1.6 眼周封锁与背景改词），每轮只能修好其中一项——模型会用自己的先验补完人脸。**图像锚点是唯一被证明能一次锁定多项约束的手段。**

## 四、稳定版提示词（短、分条、每条一个约束）

**长提示词是稳定性的天敌**：段落越长，靠后的约束越容易被稀释。以下这版把每条规则压成一句话，并在开头就锁定顺序。

```
【最高优先级，先满足再谈其他】图上所有人物一律不画眼睛：眼部区域（眉弓下沿到颧骨上沿、内眼角到外眼角这一整片）只由皮肤色块构成，一到两块最简色块、块间硬边相接；该区域内没有眼睛形状、没有上眼睑线、没有睫毛线、没有双眼皮线、没有眼白、没有瞳孔、没有高光、没有褶皱阴影，一条线都不画。
【人物】脸、鼻、下巴、衣物由大块锐利切面构成，每块内部平涂单色，块间硬边直接切换，全脸明暗不超过三块，看不到任何柔和过渡、晕染、体积感、皮肤高光。
【轮廓】人物外轮廓与服饰结构线明显加粗，面部与背景内部不加粗线。
【从简】头发用三到五块大色块，不画发丝；胡须用两三块概括暗面贴在唇周与下颌，不画胡茬；珠串每颗一个单色圆点，不加高光；纹样只保留一到两个块面或粗线；衣褶只留两三道折线。
【背景】保留原构图与元素位置，用干净平涂加单向均匀渐变：每层一个纯色块，层内沿一个方向均匀变化，三到五层；没有纹理、没有笔触、没有斑点、没有颗粒，看不到水彩或水墨痕迹；离散色块只给建筑、墙面、屋顶、器物等硬边物体；天空云雾远山一律用连续渐变；背景对比度与清晰度低于人物。
【锁定】人物数量、姿态、站位、背景布局与原图完全一致。
```

## 五、负向提示词（稳定版）

在常规负向词基础上，**必须包含以下高权重项**（位置靠前）：

```
眼睛、眼珠、眼白、瞳孔、虹膜、睫毛、睫毛线、眼线、上眼睑线、双眼皮、眼眶、眼窝阴影、眼睛高光、有眼睛的人脸、
柔和过渡、晕染、体积感、厚涂、水彩、水墨、水彩晕染、笔触、色块脏点、不匀色斑、
发丝、逐根毛发、胡茬、胡须线条、精细花纹、珠串高光、
硬边色块、马赛克、像素块、照片背景
```

> 注意 1：`水彩`、`水墨`、`笔触`、`色块脏点` 必须显式排除——只要正向里出现"柔边/柔和渐变"，模型就会滑向水彩媒介。
> 注意 2：`睫毛线`、`上眼睑线`、`双眼皮` 是实测补上的——封了眼珠之后，模型会用这几条线把眼型勾勒出来。

---

## 六、每次生成后的固定动作

1. 用 `read_image` 读回成品
2. **先放大眼窝区域**——先看眼睛，不看整体（整体观感好最容易让人放过眼睛问题）
3. 按第三节表格逐条数
4. 记录本次的失败模式（例如"眼睛第 3 次出现"），下次生成时把对应指令**提到提示词最前面**
5. 连续 2 次同一失败模式 → 切换到双参考图（原图 + 已确认样张），文字规则降级为辅助

---

## 七、已知的不稳定来源（实测记录）

| 现象 | 触发条件 | 对策 |
|---|---|---|
| 眼睛反复出现 | 提示词里"不画眼睛"排在中间或靠后 | 提到第一句，并加正面替代（第二节） |
| 背景变水彩晕染 | 只写了"柔和渐变"，没排除水彩/水墨 | 负向词加 `水彩`、`水墨晕染`、`色块脏点` |
| 细节回潮（发丝、胡须、条纹） | 规则多、约束密集，模型优先做"显眼"的细节 | 从简规则单独成句，负向词加 `发丝`、`逐根毛发` |
| 时好时坏 | 每次改词导致正/负向词版本不一致 | 固定用第四节稳定版 + 第五节负向版，不再逐次改词 |
