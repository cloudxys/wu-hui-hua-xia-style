# 无悔华夏风格转换器

把用户提供的含人物图片整体重绘为《无悔华夏》风格：人物与背景同时风格化，画风统一、构图不变。

## 一、输入

| 项目 | 要求 |
|---|---|
| 图片 | 必需，且**必须含人物**（单人、多人、带场景的人物图均可）。照片、截图、绘画不限。 |
| 风格变体 | 无。本技能只有一种标准风格，不需要询问用户选择，直接开工。 |
| 风格锚点图（可选但强烈推荐） | 用户若提供过《无悔华夏》官方立绘/截图，或本技能此前产出的满意成品，一并作为风格参考传入。 |

**开工前先检查用户是否已经发图。没有图就只索取图片，不要凭想象生成、不要用文字描述代替交付。**

## 二、人物与场景识别（调用工具前必须完成）

在把图片交给图片编辑工具之前，先自己读图（用 `read_image` 读取原图）并写下一份**清单**，作为后续核对的基准：

1. **人物数量**：画面里一共几个人（含只露半身、背影、被遮挡的人）。
2. **每个人物**：位置（左/中/右、高低）、朝向、姿态动作、服饰款式与主色、帽饰/发型/胡须、手中道具。
3. **背景场景**：**逐项列出**建筑、器物、旗帜、自然景观、人群、天空/地面等全部元素及其大致位置——这份背景清单是后面判断"背景有没有做处理、有没有分层"的依据，必须具体。
4. **画面比例**：原图宽高比与像素尺寸（用 `read_image` 返回的尺寸或读取文件属性）。

这份清单在生成后逐条比对，是验收的依据。

## 三、工作流程

1. **查图**：确认用户已提供含人物的图片；没有则索取。
2. **识图**：按第二节做人物/场景清单，**背景元素要逐项写出来**；可直接把这份清单里的关键项（人数、每个人物的位置与姿态、背景元素列表）**写进正向提示词**，比笼统的"保持原图"更稳。
3. **读提示词**：读取本技能 `references/style-prompts.md`，先过一遍第〇节的**风格锚点、优先级与硬指标**，再取出正向提示词、负向提示词，以及需要的修正指令。不要凭记忆复述，也不要另写一套。
   **若用户反馈"不稳定"、或本条提示词连续两次生成都不达标**：改读 `references/stability.md`，使用其中第四节的**稳定版提示词**（更短、每条一句话、眼睛约束放在第一句），并按第二节用"正面替代"写法描述眼窝。
4. **调工具生成**：把**用户原图当作参考图/图生图输入**，把提示词作为文本传入（调用方式见第四节）。生成参数固定为：比例=原图比例、不裁剪、不拉伸、输出 PNG、长边不低于 2048 像素。
5. **回读核对**：用 `read_image` 读回生成结果，**先放大眼窝区域**（整体好看最容易让人放过眼睛问题），再逐条过 `references/style-prompts.md` 第六节的「30 秒自检清单」。五条一票否决项都按**量化标准**核对，不做审美判断：
   - **眼睛**：眼窝区域内**色块数 = 1、线条数 = 0**（无眼珠、眼白、瞳孔、睫毛、眼线、高光、上眼睑轮廓线）；
   - **硬切面**：脸/鼻/下巴/衣物的明暗色阶 **≤ 3 块**，块与块之间**看不到过渡带**；
   - **背景**：层次 **3–5 层**、每层边界**有柔化过渡**；既不是硬边方块，也**不是水彩晕染与脏点**；
   - **从简**：头发与胡须**没有逐根线条**、珠串是单色圆点、纹样只是概括块面或粗线；
   - 人物数量、姿态、位置是否与原图一致。
   另外确认：背景每个元素都已重绘且对比度低于人物、外轮廓墨线明显加粗、主色落在色板内、人物仍可识别。
6. **交付**：把成品图以 PNG 保存到可写路径，用交付工具（`present`）呈现给用户，同时用一两句话说明成品路径与核对结论。不要添加用户未要求的文字、水印或边框。
7. **重试（有上限）**：任一条不达标，**用同一张原图和同一套提示词重生成**，并按 `references/style-prompts.md` 第三节的「失败现象 → 修正指令」表把对应指令**加到正向提示词最前面**，**最多重试 2 次**。
   - 同一失败模式连续出现 2 次（最常见是"眼睛"）→ 立即切换到 `references/stability.md` 第四节的**稳定版提示词**，并启用双参考图（原图 + 已确认样张）；
   - 再不行就如实告诉用户当前工具/模型难以稳定复现该风格，说明已尝试的指令与具体偏差，不要继续消耗、也不要交付一张自己核不过的图。

## 四、图片编辑工具调用方式

本技能依赖**图生图 / 整体风格迁移**能力，调用时遵循三条不变式：

- **参考图 = 用户上传的原图**（不是上一次的生成结果，避免误差累积；重试也必须回到原图）。
- **prompt = `references/style-prompts.md` 的正向 + 负向提示词**，原文传入。
- **尺寸 = 原图比例**，只按比例放大到长边 ≥ 2048，绝不裁剪或拉伸。

执行时的具体做法：

1. 先看当前会话实际可调用的工具清单（含动态注册的工具）。Codex 用户可用内置的 `imagegen` 技能；其它工具用自带的图像生成/编辑能力。
2. 选用其中的**图片生成/编辑类工具**执行图生图，按上面的三条不变式填参：参考图、prompt、负向 prompt、比例、PNG。
3. **双参考图用法（强烈推荐）**：若用户手上有《无悔华夏》官方截图/立绘，或有本技能产出的满意成品，把它们**与原图一起**作为风格参考传入（多数图生图工具支持多图输入）：**图1 = 原图（锁定构图与内容），图2+ = 风格锚点（锁定画风）**，并在 prompt 中写明「以图1的构图与人物为准，以图2的画风与配色为准」。当文字描述与风格锚点冲突时，**以风格锚点为准**。
4. 若当前会话**没有任何图片生成/编辑工具**：明确告知用户「本会话没有可用的图片生成/编辑工具，无法完成风格转换」，并说明需要启用这类工具（或以支持图生图的模型重开会话）后重试。**不得用文字描述、PS 滤镜、纯代码换色等方式冒充风格转换结果**，那不属于本技能的输出。

## 五、异常处理

| 情况 | 处理 |
|---|---|
| 用户没发图 | 先索取图片，说明需要含人物的图片；不要先产出。 |
| 纯风景 / 纯物品 / 无人物的图 | 说明本技能用于**含人物**的图片，请用户提供人物图；不要强行风格化。 |
| 人物过小、过多或被遮挡 | 尽量保持原数量与站位；若因此明显走形，请用户提供更清晰的图。 |
| **人物块面感弱 / 晕染过渡太多** | **最高优先级**：回原图重生成，追加第三节「硬切面」指令——每块平涂、块间硬边零过渡、明暗只 2–3 块，禁止柔和过渡、晕染、体积渲染、柔光与皮肤高光。 |
| **细节过于精致写实（珠串逐颗、纹样繁复）** | 回原图重生成，追加第三节「从简概括」指令——珠串只用单色小圆点、纹样简化为一两个概括块面或粗线、衣褶只留两三道粗折线。 |
| 画风偏厚涂 / 像商业国风立绘 | 回原图重生成，追加「去厚涂、回平涂硬切面 + 加粗墨线」指令。 |
| **人物画出了眼睛（有眼珠/眼白/睫毛/眼线）** | **最高优先级**：回原图重生成，把「不画眼睛 + 正面替代」指令**提到提示词第一句**——眼窝只画眉弓下方一整块浅色平面，区域内一个色块、零条线；连续 2 次仍出现就走 `references/stability.md`。 |
| **背景变成水彩晕染 / 有色块脏点** | 回原图重生成，追加第三节「干净柔边云气」指令：3–5 层模糊淡入、层间带雾、过渡均匀；不要水彩笔触、水墨晕染、脏点与不匀色斑。 |
| **头发/胡须出现逐根线条** | 回原图重生成，追加第三节「头发不发丝」指令：头发 3–5 块大色块、胡须与眉毛用概括色块、发际线一条粗线带过。 |
| **同一条提示词时好时坏** | 读 `references/stability.md`：固定使用第四节的稳定版提示词与第五节的稳定版负向词，不再逐次改词；连续 2 次同一失败模式即切换双参考图。 |
| **背景变成硬边色块 / 马赛克 / 像素块** | 回原图重生成，追加第三节「柔边云气渐变」指令：同类元素 3–5 层模糊淡入、层间带雾，禁止硬边、马赛克、棋盘格、几何切块。 |
| 背景没处理（保留原照片/纹理/噪点） | 回原图重生成，追加第三节「背景逐元素重绘」指令；重试时明确写出背景里有哪些元素需要重绘。 |
| 背景糊成一片 / 没有层次 | 回原图重生成，追加第三节「背景分层」指令：3–5 层明度逐层柔和淡入，相邻层明度差约 8–15%。 |
| 背景太碎 / 太抢眼 | 回原图重生成，追加第三节「简化背景」指令：层次减少、对比度与清晰度降到人物之下。 |
| 生成后人物增减、姿态改变 | 回原图重生成，追加「锁定人数/姿态/站位」指令。 |
| 面部偏深、细节过多、有黑眼线 | 回原图重生成，追加「面部只用浅色块+大块阴影、五官极简、不画眼睛」指令。 |
| 画面发灰发糊、像加了滤镜 | 回原图重生成，追加「提高块面对比、去除虚化与灰雾」指令。 |
| 轮廓线太弱 | 回原图重生成，追加「外轮廓与服饰结构线明显加粗」指令。 |
| 颜色太艳 / 太现代 | 回原图重生成，追加「改用国风低饱和色板」指令。 |
| 反复重试仍不到位 | 让用户提供 1–2 张《无悔华夏》官方立绘作为**风格锚点图**，改用双参考图模式（第四节第 3 条）再生成。 |
| 低俗、违规、侵权内容 | 拒绝风格化，并说明原因。 |
| 用户只要求改风格 | 除风格转换外不动原图任何内容（不加字、不加边框、不换构图）。 |

## 六、输出规格

- 格式：PNG（.png 结尾的可写路径）。
- 比例：严格等于原图。
- 分辨率：长边 ≥ 2048 像素。
- 内容：只做风格转换，不附加文字、水印、边框。

## 七、验收标准

1. 单人、多人、人物场景图都能稳定转换；人物数量、姿态、位置与原图一致。
2. **人物是硬切面**：脸、鼻、下巴、衣物的明暗由大块锐利切面构成，块内平涂、块间硬边零过渡、明暗仅 2–3 块；放大看不到柔和晕染、体积渲染与皮肤高光。
3. **从简到位**：珠串是单色小圆点（无高光无立体感）、纹样只是概括块面或粗线条、衣褶仅两三道粗折线——整体"概括"而非"精致"。
4. **所有人物都没有眼睛**：眼窝区域内**色块数 = 1、线条数 = 0**，无眼珠、眼白、瞳孔、睫毛、眼线、高光——最容易翻车，必须放大检查。
5. **背景由干净的柔边云气渐变重绘**：每个元素都已重画，3–5 层模糊淡入、层间带雾、有空气感；不是硬边色块/马赛克/像素块，**也不是水彩晕染与脏点**；全图没有照片纹理与噪点；背景对比度低于人物。
6. 画面具备：明显加粗的外轮廓墨线、面部为浅色块+大块阴影、国风低饱和色板（主色落在 `references/style-prompts.md` 第五节色域内）。
7. 人物可识别特征保留，不会变成另一个人。
8. **稳定性**：同一张原图连续两次生成，五项一票否决项均应通过；若出现同一失败模式反复，按 `references/stability.md` 切换到稳定版提示词与双参考图，而不是继续微调词句。
9. 全流程无需用户反复补充信息或选择变体即可完成并交付成品图。

## 八、技能文件

| 文件 | 内容 |
|---|---|
| `references/style-prompts.md` | 风格锚点与硬指标（含"不画眼睛""背景柔边渐变"两条强制项与优先级顺序）、正向/负向提示词（含单行版）、失败现象→修正指令表、输出参数、国风色板、量化自检清单（唯一提示词来源） |
| `references/stability.md` | 稳定性规范：优先级、正面替代写法、量化验收、稳定版短提示词、固定负向词、失败模式实测记录（"不稳定"时必读） |
